# LearnHub Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the production-shaped LearnHub foundation: Next.js app scaffold, database schema, tenant/auth primitives, provider boundaries, audit helpers, date utilities, and seed data.

**Architecture:** Implement the first slice as a modular monolith with clear internal modules under `src/modules`. Keep provider adapters interface-first so video, storage, email, and credential systems can be wired in later plans without rewriting domain code.

**Tech Stack:** Next.js, TypeScript, Tailwind CSS, PostgreSQL, Prisma, Auth.js-compatible auth primitives, Vitest, Zod, bcryptjs.

---

## Scope Boundary

This plan implements the foundation only. The approved MVP spec covers several independent subsystems, so execution is split into separate implementation plans. This foundation plan prepares the repo for later subsystem plans covering full auth screens, course authoring, native video, SCORM runtime, certificates, notifications, reporting, and deployment.

This plan produces a runnable app with a database schema, generated Prisma client, seed data, basic route shells, reusable utilities, provider interfaces, and tests.

function isWeekend(date: Date): boolean {
  const day = date.getUTCDay();

  return day === 0 || day === 6;
}

export function addBusinessDays(startDate: Date, businessDays: number): Date {
  if (businessDays < 0) {
    throw new Error("Business day count cannot be negative");
  }

  const dueDate = new Date(startDate);
  let remaining = businessDays;

  while (remaining > 0) {
    dueDate.setUTCDate(dueDate.getUTCDate() + 1);

    if (!isWeekend(dueDate)) {
      remaining -= 1;
    }
  }

  return dueDate;
}
```

import bcrypt from "bcryptjs";

const SALT_ROUNDS = 12;
const MIN_PASSWORD_LENGTH = 12;

export async function hashPassword(password: string): Promise<string> {
  if (password.length < MIN_PASSWORD_LENGTH) {
    throw new Error("Password must be at least 12 characters");
  }

  return bcrypt.hash(password, SALT_ROUNDS);
}

export async function verifyPassword(password: string, hash: string): Promise<boolean> {
  return bcrypt.compare(password, hash);
}
```
